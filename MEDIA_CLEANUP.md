# Очистка неиспользуемых медиа

Дата: 29 октября 2026 года.

Удалены **1056 исходных файлов**, общим размером **5 094 934 байта (4,86 МиБ)**,
и **1056 совпадающих копий** из `staticfiles/`.

В список вошли неиспользуемые видео, фоны, превью и старые изображения шаблона.
Самый крупный файл — `core/static/core/video/presentation.mp4` (3,03 МиБ).
Перед удалением проверены прямые ссылки, текстовый контент БД и пути без
расширения, которые могут использоваться видеоплагинами.

## Что сохранено

- Все 51 файл в `media/`, связанные с записями базы.
- Демоматериалы и файлы демозаписей.
- Запасные изображения, логотипы и favicon.
- Шрифты, CSS и JavaScript.
- Ресурсы сторонних плагинов и библиотеки иконок с возможными динамическими путями.

Хеши **6100 сохранённых файлов** проверены после очистки и совпадают
с состоянием до удаления. Записи рабочей базы не изменялись.

| Подключённые CSS и вложенные URL ресурсов | 14 CSS, отсутствующих файлов нет |
| Автоматические тесты SQLite | 128 тестов: 127 прошли, 1 PostgreSQL-тест пропущен |
| Django system checks | Ошибок нет |

Набор ресурсов страниц до и после удаления совпадает. Проверка выполнялась
рендерингом страниц и обходом локальных URL, включая зависимости CSS.
