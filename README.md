# TÜKİD

Сайт общественного объединения турецко-кыргызских предпринимателей. Здесь можно познакомиться с компаниями объединения, почитать новости, узнать о ближайших встречах, подать заявку на членство или найти работу у участников.

Сайт работает на русском, кыргызском и турецком языках. Редакторы обновляют материалы через админку: добавляют новости и фотографии, публикуют вакансии, меняют меню и тексты страниц.

## Сторонние материалы

В проекте используются сторонний шаблон, библиотеки, иконки и шрифты. Их лицензионные условия сохранены рядом с соответствующими файлами. Общая лицензия для собственного кода проекта пока не задана.
