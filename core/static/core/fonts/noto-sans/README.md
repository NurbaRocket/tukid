# Noto Sans

Локальный вариативный WOFF2, вес 100–900, обычная ширина. Подмножество содержит
латиницу, турецкий алфавит, кириллицу и кыргызские буквы Өө Үү Ңң.
Одна гарнитура используется для всего текста, включая поля форм и кнопки.

Источник: https://github.com/google/fonts/tree/main/ofl/notosans
Исходник: `NotoSans[wdth,wght].ttf`, загружен 29 октября 2026 года.
Ширина зафиксирована на 100, подмножество создано FontTools, формат WOFF2.
Лицензия SIL Open Font License 1.1 находится в `OFL.txt`.
Внешние запросы к Google Fonts посетителю не требуются.
